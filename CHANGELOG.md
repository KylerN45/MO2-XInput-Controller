# Changelog

All notable changes to this project are documented here.

## 0.1.0 - 2026-09-20

- Added dependency-free XInput polling for controllers 0-3.
- Added automatic controller discovery and sticky selection.
- Added executable selection with D-pad, shoulders, and left stick.
- Added edge-triggered A-button activation of MO2's native Run button.
- Added focus, modal-dialog, disconnect, and neutral-rearm safety gates.
- Added MO2 plugin settings, Windows CI, and release packaging.
